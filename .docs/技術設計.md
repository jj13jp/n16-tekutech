# 技術設計

## ファイル構成

```
src/
├── app/
│   ├── layout.tsx               # ルートレイアウト・共通 OGP/SEO
│   ├── page.tsx                 # 記事一覧（トップ）
│   ├── articles/[slug]/
│   │   └── page.tsx             # 記事詳細
│   ├── categories/[slug]/
│   │   └── page.tsx             # カテゴリ別記事一覧
│   ├── tags/[slug]/
│   │   └── page.tsx             # タグ別記事一覧
│   └── search/
│       └── page.tsx             # キーワード検索結果
├── components/
│   ├── ArticleCard.tsx          # 記事カードコンポーネント
│   ├── Pagination.tsx           # ページネーション
│   └── SearchForm.tsx           # 検索フォーム（Client Component）
├── lib/
│   ├── microcms.ts              # microCMS データ取得関数
│   └── sanitize.ts              # HTML サニタイズ（sanitize-html）
└── types/
    └── microcms.ts              # microCMS コンテンツ型定義
```

## 主要な設計決定

### レンダリング戦略

- **ISR（Incremental Static Regeneration）** を採用
- 記事・記事詳細: `revalidate: 60`（1 分ごとに再生成）
- カテゴリ・タグ: `revalidate: 3600`（1 時間ごとに再生成）
- `generateStaticParams` でビルド時に全パスを静的生成

### HTML サニタイズ

- microCMS リッチエディタの出力を `sanitize-html` でサニタイズしてから `dangerouslySetInnerHTML` に渡す
- 許可タグ: 見出し、段落、リスト、コード、画像、テーブルなど標準的な HTML 要素
- 外部リンクに自動で `rel="noopener noreferrer"` と `target="_blank"` を付与

### ページネーション

- 1 ページあたり `PER_PAGE = 10` 件
- クエリパラメータ `?page=n` で制御

### SEO / OGP

- `layout.tsx` でサイト共通のタイトルテンプレート（`%s | Tech まとめブログ`）を設定
- 各ページで `generateMetadata` を使って個別のタイトル・説明・OGP を設定
- 記事詳細ページはカバー画像を OGP 画像として設定

## 環境変数

| 変数名 | 説明 |
|--------|------|
| `MICROCMS_SERVICE_DOMAIN` | microCMS のサービスドメイン（`xxxx.microcms.io` の `xxxx` 部分） |
| `MICROCMS_API_KEY` | microCMS の API キー |

`.env.local` に設定する（`.env.local.example` を参照）。
