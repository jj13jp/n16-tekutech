# 技術設計

## ファイル構成

機能ベース（Feature-based）フォルダ構成を採用する。各機能（articles / categories / tags / search）を `features/` 配下にまとめ、横断的関心事は `shared/` に置く。`app/` はルーティングのみを担う。

```
src/
├── app/                                    # ルーティングのみ
│   ├── layout.tsx                          # ルートレイアウト・共通 OGP/SEO
│   ├── error.tsx                           # API エラー時のフォールバック
│   ├── page.tsx                            # 記事一覧（トップ）
│   ├── articles/[id]/page.tsx              # 記事詳細
│   ├── categories/[id]/page.tsx            # カテゴリ別記事一覧
│   ├── tags/[id]/page.tsx                  # タグ別記事一覧
│   └── search/page.tsx                     # キーワード検索結果
├── features/
│   ├── articles/
│   │   ├── api.ts                          # 記事取得（一覧・詳細・全ID・検索・カテゴリ/タグ絞り込み）
│   │   ├── types.ts                        # Article 型
│   │   └── components/ArticleCard.tsx      # 記事カードコンポーネント
│   ├── categories/
│   │   ├── api.ts                          # カテゴリ一覧取得
│   │   └── types.ts                        # Category 型
│   ├── tags/
│   │   ├── api.ts                          # タグ一覧取得
│   │   └── types.ts                        # Tag 型
│   └── search/
│       └── components/SearchForm.tsx       # 検索フォーム（Client Component）
└── shared/                                 # 機能横断の共通モジュール
    ├── components/Pagination.tsx           # ページネーション
    └── lib/
        ├── microcms.ts                     # microCMS クライアント・PER_PAGE
        └── sanitize.ts                     # HTML サニタイズ（sanitize-html）
```

### 構成の方針

- `app/` はルーティングと各ページの組み立てに専念し、データ取得・型・UI 部品は `features/` から import する。
- データ取得関数は機能ごとの `api.ts` に分離する。記事を対象とする取得（検索・カテゴリ/タグ絞り込みを含む）は `features/articles/api.ts` に集約する。
- 型は機能ごとの `types.ts` に分離する。`Article` 型は `Category` / `Tag` 型を参照する。
- microCMS クライアント本体と `PER_PAGE` などの共通定数は `shared/lib/microcms.ts` に置き、各 `api.ts` がこれを利用する。
- import は TypeScript パスエイリアス `@/*`（`./src/*`）で行う。

## 主要な設計決定

### レンダリング戦略

- **ISR（Incremental Static Regeneration）** を採用
- 記事・記事詳細: `revalidate: 60`（1 分ごとに再生成）
- カテゴリ・タグ: `revalidate: 3600`（1 時間ごとに再生成）
- `generateStaticParams` でビルド時に全パスを静的生成

### HTML サニタイズ

- microCMS リッチエディタの出力を `sanitize-html` でサニタイズしてから `dangerouslySetInnerHTML` に渡す
- 許可タグ: 見出し、段落、リスト、コード、画像、テーブルなど標準的な HTML 要素
- 外部リンクに自動で `rel="noopener noreferrer"` と `target="_blank"` を付与

### ページネーション

- 1 ページあたり `PER_PAGE = 10` 件
- クエリパラメータ `?page=n` で制御

### SEO / OGP

- `layout.tsx` でサイト共通のタイトルテンプレート（`%s | Tech まとめブログ`）を設定
- 各ページで `generateMetadata` を使って個別のタイトル・説明・OGP を設定
- 記事詳細ページはカバー画像を OGP 画像として設定

## 環境変数

| 変数名 | 説明 |
|--------|------|
| `MICROCMS_SERVICE_DOMAIN` | microCMS のサービスドメイン（`xxxx.microcms.io` の `xxxx` 部分） |
| `MICROCMS_API_KEY` | microCMS の API キー |

`.env.local` に設定する（`.env.local.example` を参照）。
