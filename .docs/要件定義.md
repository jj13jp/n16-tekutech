# まとめブログ 要件定義

## プロジェクト概要

技術・IT 系の情報をキュレーションして発信する静的ブログサイト。microCMS をヘッドレス CMS として使い、Next.js でフロントエンドを構築する。

---

## 技術スタック

| 役割 | 技術 |
|------|------|
| フレームワーク | Next.js（現プロジェクト: n16-afi） |
| CMS | microCMS |
| スタイリング | Tailwind CSS（既存） |
| デプロイ | 未定（Vercel 推奨） |

---

## 機能要件

### 必須機能

| # | 機能 | 説明 |
|---|------|------|
| F1 | 記事一覧 | 最新順で記事を一覧表示。ページネーションあり |
| F2 | 記事詳細 | タイトル・本文・カバー画像・投稿日・カテゴリ・タグを表示 |
| F3 | カテゴリ一覧 | カテゴリ別に記事を絞り込み表示 |
| F4 | タグ一覧 | タグ別に記事を絞り込み表示 |
| F5 | キーワード検索 | タイトル・本文をキーワードで検索 |
| F6 | OGP / SEO | 各ページに適切なメタタグ・OGP を設定 |

### 対象外

- ユーザー登録・ログイン（閲覧のみ公開）
- コメント機能
- RSS フィード

---

## microCMS スキーマ設計

### 記事（articles）

| フィールド | 型 | 説明 |
|-----------|-----|------|
| title | テキスト | 記事タイトル |
| body | リッチエディタ | 本文 |
| coverImage | 画像 | カバー画像 |
| category | コンテンツ参照 | カテゴリ（複数不可） |
| tags | 複数コンテンツ参照 | タグ（複数可） |
| summary | テキスト | 抜粋・サマリー（OGP 用） |

### カテゴリ（categories）

| フィールド | 型 |
|-----------|-----|
| name | テキスト |
| slug | テキスト |

### タグ（tags）

| フィールド | 型 |
|-----------|-----|
| name | テキスト |
| slug | テキスト |

---

## ページ構成

```
/                      トップ（記事一覧）
/articles/[id]         記事詳細
/categories/[id]       カテゴリ別記事一覧
/tags/[id]             タグ別記事一覧
/search?q=xxx          検索結果
```

---

## 非機能要件

- **レンダリング**: ISR（Incremental Static Regeneration）でパフォーマンスと更新頻度を両立
- **レスポンシブ**: モバイル・タブレット・PC 対応
- **アクセシビリティ**: セマンティック HTML、適切な alt テキスト
