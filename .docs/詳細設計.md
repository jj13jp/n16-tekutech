## 2. 型定義（src/types/microcms.ts）

```typescript
import type { MicroCMSImage, MicroCMSListContent } from "microcms-js-sdk"

export type Category = MicroCMSListContent & {
  name: string
}

export type Tag = MicroCMSListContent & {
  name: string
}

export type Article = MicroCMSListContent & {
  title: string
  body: string
  summary?: string
  coverImage?: MicroCMSImage
  category: Category
  tags: Tag[]
}
```

## 3. データ取得レイヤー（src/lib/microcms.ts）

### 定数

| 定数 | 値 | 説明 |
|------|-----|------|
| `PER_PAGE` | `10` | 1 ページあたりの記事件数 |

### 関数一覧

| 関数名 | 引数 | 戻り値 | 説明 |
|--------|------|--------|------|
| `getArticles` | `page?: number`, `queries?: object` | `MicroCMSListResponse<Article>` | 記事一覧取得（`use cache` / revalidate: 60s） |
| `getArticle` | `contentId: string` | `Article` | 記事詳細取得（`use cache` / revalidate: 60s） |
| `getAllArticleIds` | なし | `string[]` | 全記事 ID 取得（`use cache` / revalidate: 60s） |
| `getCategories` | なし | `MicroCMSListResponse<Category>` | カテゴリ一覧取得（`use cache` / revalidate: 3600s） |
| `getTags` | なし | `MicroCMSListResponse<Tag>` | タグ一覧取得（`use cache` / revalidate: 3600s） |
| `searchArticles` | `q: string`, `page?: number` | `MicroCMSListResponse<Article>` | キーワード検索（`use cache` / revalidate: 60s, stale: 0） |
| `getArticlesByCategory` | `categoryId: string`, `page?: number` | `MicroCMSListResponse<Article>` | カテゴリ絞り込み（`use cache` / revalidate: 60s） |
| `getArticlesByTag` | `tagId: string`, `page?: number` | `MicroCMSListResponse<Article>` | タグ絞り込み（`use cache` / revalidate: 60s） |

### microCMS API クエリ詳細

**getArticles（ベース）**

```
GET /api/v1/articles
  ?limit=10
  &offset=(page-1)*10
  &orders=-publishedAt
  &depth=2
```

**searchArticles**

```
GET /api/v1/articles
  ?q={keyword}
  &limit=10
  &offset=(page-1)*10
  &orders=-publishedAt
  &depth=2
```

**getArticlesByCategory**

```
GET /api/v1/articles
  ?filters=category[equals]{categoryId}
  &limit=10
  &offset=(page-1)*10
  &orders=-publishedAt
  &depth=2
```

**getArticlesByTag**

```
GET /api/v1/articles
  ?filters=tags[contains]{tagId}
  &limit=10
  &offset=(page-1)*10
  &orders=-publishedAt
  &depth=2
```

> `depth=2` を指定することで、category・tags の参照先フィールドまで展開して取得する。

## 4. コンポーネント詳細設計

### ArticleCard

**Props**

| プロパティ | 型 | 説明 |
|-----------|-----|------|
| `article` | `Article` | 表示する記事データ |

**表示要素**

- カバー画像（存在する場合のみ）: `next/image` で表示。アスペクト比 16:9
- 投稿日: `publishedAt` を `ja-JP` ロケールで整形
- カテゴリ: ラベルリンク → `/categories/[id]`
- タイトル: リンク → `/articles/[id]`。2 行でクランプ
- サマリー: 存在する場合のみ。3 行でクランプ
- タグ: 各タグリンク → `/tags/[id]`

### Pagination

**Props**

| プロパティ | 型 | 説明 |
|-----------|-----|------|
| `totalCount` | `number` | 総記事件数 |
| `currentPage` | `number` | 現在のページ番号 |
| `basePath` | `string` | ページリンクのベース URL |

**ロジック**

- `totalPages = Math.ceil(totalCount / PER_PAGE)`
- `totalPages <= 1` の場合は何も描画しない
- ページ 1 のリンクは `basePath`（クエリなし）、2 以降は `{basePath}?page={n}`

### SearchForm

**Props**

| プロパティ | 型 | デフォルト | 説明 |
|-----------|-----|-----------|------|
| `defaultValue` | `string` | `""` | 初期表示のキーワード |

**動作**

- `"use client"` 指定の Client Component
- フォーム送信時に `router.push("/search?q={keyword}")` で遷移
- キーワードが空の場合は遷移しない

## 5. ページ詳細設計

### app/layout.tsx

- `SITE_NAME`・`SITE_DESCRIPTION` を定数で定義
- `metadata.title.template` に `"%s | {SITE_NAME}"` を設定（各ページのタイトルに自動でサイト名が付く）
- OGP の `type: "website"`、Twitter Card の `card: "summary_large_image"` を設定

### app/page.tsx（記事一覧）

**データ取得**

- `searchParams.page` を数値変換（デフォルト 1）
- `getArticles(currentPage)` で記事一覧を取得

**metadata**

```typescript
{ title: "Tech まとめブログ", description: "..." }
```

**描画**

- 記事がゼロ件の場合: 「記事がまだありません。」を表示
- 記事がある場合: `ArticleCard` を縦に並べる
- 下部に `Pagination`（`basePath="/"`)

### app/articles/[id]/page.tsx（記事詳細）

**generateStaticParams**

- `getAllArticleIds()` で全 ID を取得してビルド時に静的生成

**データ取得**

- `getArticle(id)` で記事を取得
- 取得失敗（404 等）の場合は `notFound()` を呼ぶ

**generateMetadata**

```typescript
{
  title: article.title,
  description: article.summary,
  openGraph: {
    title: article.title,
    description: article.summary,
    images: [{ url: article.coverImage.url }],  // カバー画像がある場合
  },
}
```

**描画**

- ヘッダー: 投稿日・カテゴリ・タイトル・タグ・カバー画像（存在する場合）
- 本文: `sanitizeContent(article.body)` を `dangerouslySetInnerHTML` でレンダリング
- フッター: 「記事一覧に戻る」リンク（`/`）

### app/categories/[id]/page.tsx（カテゴリ別一覧）

**generateStaticParams**

- `getCategories()` で全カテゴリを取得してビルド時に静的生成

**データ取得**

- `getCategories()` でカテゴリ情報を取得（ページタイトル表示用）
- 該当カテゴリが存在しない場合は `notFound()`
- `getArticlesByCategory(id, currentPage)` で記事一覧を取得

### app/tags/[id]/page.tsx（タグ別一覧）

カテゴリ別一覧と同構造。`getCategories` の代わりに `getTags`、`getArticlesByCategory` の代わりに `getArticlesByTag` を使用。

### app/search/page.tsx（検索結果）

**データ取得**

- `searchParams.q` が空の場合はデータ取得しない（空リストを返す）
- `searchParams.q` がある場合は `searchArticles(q, currentPage)` で取得

**描画**

- 検索フォームを常に表示（`defaultValue` に現在のクエリをセット）
- クエリがある場合: 「"{q}" の検索結果: {totalCount} 件」を表示
- 結果 0 件の場合: 「該当する記事が見つかりませんでした。」を表示

## 6. エラーハンドリング方針

| ケース | 対応 |
|--------|------|
| 存在しない記事 ID へのアクセス | `notFound()` → Next.js デフォルトの 404 ページ |
| 存在しないカテゴリ / タグ ID へのアクセス | `notFound()` → 同上 |
| microCMS API エラー（ネットワーク等） | エラーが上位に伝播し、`app/error.tsx` で受け取って表示 |
| 検索クエリなしの `/search` アクセス | エラーなし。検索フォームのみ表示 |

## 7. 環境変数

| 変数名 | スコープ | 説明 |
|--------|---------|------|
| `MICROCMS_SERVICE_DOMAIN` | サーバーのみ | microCMS のサービスドメイン（`xxxx.microcms.io` の `xxxx` 部分） |

## 8. HTML サニタイズ仕様（src/lib/sanitize.ts）

microCMS リッチエディタの出力に対して `sanitize-html` を適用する。

**許可タグ**

見出し（h1–h6）、段落（p, br, hr）、リスト（ul, ol, li）、インライン装飾（strong, em, s, u, code）、ブロック（pre, blockquote, div, span）、リンク（a）、画像（img）、テーブル（table, thead, tbody, tr, th, td）

**許可属性**

- `a`: `href`, `target`, `rel`
- `img`: `src`, `alt`, `width`, `height`
- 全タグ共通: `class`

**変換ルール**

- `http` / `https` 以外のスキームを持つリンクは除去
- 外部リンク（`href` が `http` で始まる）に `target="_blank"` と `rel="noopener noreferrer"` を自動付与
